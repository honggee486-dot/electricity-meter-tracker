# electricity-meter-tracker

계량기 누적값을 빠르게 기록하고 실제 검침주기와 사용 추세를 계산하는 모바일 중심 웹앱.

## 핵심 입력 흐름

```text
앱 실행
→ 현재 계량기 누적값 입력
→ 저장
→ 사용 현황 확인
```

기록 시각은 기본적으로 자동 입력됩니다.

## 주요 제품 방향

* **임의 시점 계량기 기록**: 언제든 현재 계량기 누적값을 기록
* **계량기별 검침 마감일**: 계량기별로 서로 다른 정기 검침일 기준 관리
* **일별 사용량**: 시간대별/일자별 사용량 산출
* **검침주기 사용량**: 현재 검침주기 내 실제 사용량 산출
* **사용량 예측**: 검침 마감일까지의 예상 사용량 및 비교용 30일 환산 사용량 계산
* **예상 전기요금**: 구간별 누진제 등 요금 기준에 따른 예상 요금 산정
* **Google 로그인**: 간편하고 안전한 단일 인증 체계
* **사용자별 계량기**: 사용자별 독립 데이터 격리
* **선택적 계량기 공유**: 필요 시 특정 계량기를 타 사용자와 공유
* **모바일/PWA**: 모바일 환경 우선 UI/UX
* **운영비 0원 우선**: 무료 티어 인프라 활용 최적화

## 현재 상태

현재 단계: **초기 repository bootstrap** 단계

* 기술 스택 유력 후보: Cloudflare Workers / Pages (또는 static assets), Cloudflare D1, Google OAuth
* 현재는 기본 문서 및 저장소 기준만 정의된 상태이며, 프론트엔드/백엔드 구현, 데이터베이스, 인증, 계산 로직 등은 아직 구현되지 않았습니다.

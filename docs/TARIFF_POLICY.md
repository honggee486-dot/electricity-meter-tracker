# Tariff policy contract

## 범위

전기요금 policy는 순수 사용량 domain(`src/domain/usage.ts`, `forecast.ts` 등)과 분리된 독립 모듈(`src/domain/tariff.ts`)입니다. policy 모듈은 정수 Wh 총사용량과 검침 마감 월만 입력으로 받고 usage/billing/calendar 내부를 import하지 않습니다.

현재 v2 범위(주택용(저압), standard no-discount household의 **예상 전기요금**):

- 주택용(저압) 2023-11-09 개정적용 버전 1개
- 하계(마감 월 7~8월) 300/450kWh 확대 누진 구간
- 동계(마감 월 12·1·2월)와 기타계절(3·4·5·6·9·10·11월) 200/400kWh 누진 구간
- 슈퍼유저요금: 여름철·겨울철(하계 7~8월, 동계 12~2월) 마감 월의 1,000kWh 초과분에 736.2원/kWh
- 기본요금(호당)과 전력량요금(kWh당)
- 기후환경요금 9.0원/kWh(사용량 곱)
- 연료비조정요금: 분기별 공식 고지 단가만 명시적 window로 적용
- 월간 최저요금 1,000원(전기요금 단계에 적용)
- 부가가치세 10%(과세기준 전기요금, 원 단위 4사5입)
- 전력산업기반기금(과세기준 전기요금, 요율별 window, 10원 미만 절사)
- policy version, 적용 마감 월 창(window), 공식 출처 provenance, 저장소 확인일
- 항목별 내역(appliedComponents), 전기요금(electricityChargeWon), 예상 합계(estimatedTotalWon), 명시적 미반영 항목 목록

명시적으로 포함하지 않음:

- 복지할인(구 필수사용량보장공제) — 사용자 자격 입력이 필요한 별도 optional policy. baseline은 "복지/대가족/출산/생명유지장치 할인 없음"이며, 200kWh 이하 사용자에게 일괄 감액을 적용하지 않습니다.
- TV수신료 — 전기요금이 아니라 함께 청구될 수 있는 별도 부담 항목(약관 제82조 병기청구). tariff total에 넣지 않습니다.
- 동계 소용량 할인 — 현행 약관에는 독립 제도가 없습니다(별표1 가.(4)가 `<삭 제>` 처리, 생활법령정보 2026-08-15 기준 할인 목록에 부재). 200kWh 이하 지원은 복지할인 추가감액으로 흡수되어 복지할인 후속 항목으로만 다룹니다.
- 2026-10 이후 연료비조정단가 — 4분기 공식 공시가 확인되기 전까지 미커버이며, 직전 분기 값을 자동 연장하지 않습니다.

## 계산 규칙

- 계절은 검침주기의 마감 월(close month) 기준으로 선택합니다. v2부터 동계(12·1·2월)는 슈퍼유저요금이 있는 별도 season이고, 슈퍼유저요금은 여름철·겨울철에만 존재하므로 기타계절의 최상단 구간은 307.3원/kWh가 열려 있어도 그것이 공식 표 그대로입니다.
- 슈퍼유저요금은 1,000kWh 초과분에만 부과됩니다(한계 방식). 별표1은 기본요금 구간을 200/400(하계 300/450) 3단으로만 정의하므로, 1,000kWh 초과 band는 같은 최상단 기본요금(7,300원)을 재사용합니다. 이는 별표1 구조와 결과가 동일한 표현입니다.
- 전력량요금은 총사용량을 구간별 Wh로 분할해 구간 단가와 곱합니다. 곱은 BigInt로 1/10,000원 단위까지 정확히 누적하고 최종적으로 1원 단위 반올림(half-up)을 한 번 적용합니다. 항목별 원단위 반올림의 공식 문구가 항목마다 확인되지 않아 이 반올림은 저장소 v2 규칙입니다.
- 기후환경요금·연료비조정요금은 사용량(Wh) × 단가(0.1원/kWh)를 같은 1/10,000원 단위로 누적 후 1원 half-up 1회입니다. 연료비조정단가는 음수가 될 수 있어 signed 반올림(half away from zero)을 사용합니다.
- 전기요금(electricityChargeWon) = 기본요금 + 전력량요금 + (해당 월에 커버되는) 기후환경요금 + 연료비조정요금이며, 별표1 가.(3)에 따라 월간 최저요금 1,000원 미만이 되지 않습니다.
- 부가가치세 = 전기요금 × 10%, 원 단위 미만 4사5입(부가가치세법 제30조 + 한전ON 공식 계산식). 전력산업기반기금은 VAT 과세대상이 아닙니다(국세청 유권해석 재소비46015-118).
- 전력산업기반기금 = 전기요금 × 요율, 10원 미만 절사(한전ON 공식 계산식 + 2023-11-09 공식 요금표 PDF). 요율은 3.7%(2023-11~2024-06), 3.2%(2024-07~2025-06), 2.7%(2025-07~) window로 관리합니다.
- estimatedTotalWon = 전기요금 + 부가가치세 + 전력산업기반기금의 합에서 10원 미만을 절사합니다(약관 제7조②, 한전ON 청구요금 합계 계산식). TV수신료는 포함하지 않습니다.
- 결과는 항상 **예상 전기요금**이며 실제 청구액을 대표하지 않습니다. "실제 청구액의 약 N%" 같은 고정 비율 표현을 사용하지 않습니다.
- 미커버 항목(예: 2026-10 이후 연료비조정요금)은 계산에서 빠지고 결과의 `excludedComponents`에 그 마감 월 기준으로 나열됩니다. policy window 자체가 없는 마감 월(2023-10 이전)은 `NO_TARIFF_POLICY_VERSION` 오류입니다.

## 검증

`domain-tests/tariff.test.mjs`가 공식 표 기준 기대값으로 다음을 검증합니다.

- policy registry + per-kWh component windows + tax windows의 유효성(versionId, 출처, 확인일, 계절 전체 커버, window 겹침 금지, 반올림 규칙 고정)
- 구간 경계(이하/초과) 기본요금 전환, 0 사용량 최저요금 1,000원
- 하계/동계/기타계절 구분과 슈퍼유저요금 999/1,000/1,001kWh 경계(하계·동계 적용, 기타계절 미적용)
- 연료비조정 +5.0원/kWh의 2026-07·08·09 적용, 2026-06은 2분기 window, 2026-03·2026-10·2027-01은 미커버 excluded
- 기후환경요금 9.0원/kWh와 window
- 부가가치세 원 단위 4사5입 경계(28,515원 → 2,852원)와 기금 10원 절사(3.7%/3.2%/2.7% window별)
- estimatedTotalWon의 10원 미만 절사(148,464 → 148,460)
- 미커버 마감 월, 잘못된 사용량/월, window 겹침, band 위반의 명시적 오류 코드

```sh
npm run test:domain
```

`tests/ui.spec.ts`는 고정 시각 mock에서 홈 화면 예상 전기요금이 정확한 원 단위(예상 합계)와 provenance 문구(개정적용일, 확인일, 포함 항목, 연료비 고지 window와 단가, 미반영 항목)로 렌더링되는지 검증합니다. UI는 policy가 커버하지 않는 마감 월에서 기존 `요금 정책 연결 전` 문구를 유지하고, 계산 입력이 부족하면 `자료 부족`을 표시하면서도 해당 월의 포함/미반영 항목 안내는 유지합니다.

## Runtime evidence 경계

Repository test는 정책 데이터와 계산식의 일관성만 검증합니다. 실제 한전 청구서와의 대조, 분기별 연료비조정단가 공시 추적, 하계/동계 실측 검증은 이 모듈 범위가 아니며 별도 확인이 필요합니다. 실제 청구액 비교가 필요해지면 component window를 새 데이터로 먼저 갱신합니다. 복지할인(자격 입력)과 TV수신료(별도 청구 항목)는 `docs/TARIFF_V2_RESOLUTION.md`의 후속 항목입니다.
